# Tressa Millering's Portfolio Website
This is my portfolio website; it showcases my skill set, projects, work experience, and more! Every element on the page is fully responsive, animated where necessary, and built entirely with pure HTML, CSS, and JavaScript in order to challenge myself and my web design abilities; no heavy frameworks or BootStrap to pick up the slack. 

The site is modularly designed to keep things neat and organized and prevent element code from becoming convoluted or codependent. 
Instead of spaghetti code, it is made of clean building blocks; all of which is responsively designed. 

I'm particularly proud of the navigation bars, image carousel, and project cards. The navbar is entirely responsive, and at a small enough screen size is replaced with a toggling menu. The carousel is elegantly intuitive without being obstructive to the user, allowing one to see my lighting design work. Lastly, the project cards flip on hover to show extra information, and  open a modal element when clicked for more information.
