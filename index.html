Paint Blob Simulation

Python TKinter MatPlotLib
This script simulates randomly dropping red, green, or blue paint blobs onto an empty canvas. Each tick, a blob is dropped at a random location, fully covering any prior blobs. Multiple experiments are run using parameters provided by the user.
It keeps track of a variety of stats, including the number of blobs dropped on each square of each color, squares that have only been hit by a single color, and of course the number of blobs dropped so far. This program features a full GUI built with TKinter. Shown in this GUI is a full animation of the simulation as it runs, a statistical analysis of data gathered from the simulation, and graph that depicts data gathered from a batch simulation set as per user choice.

Lexicographical Analyzer

C++
This is a lexicographical analyzer built in C++. This coming semester I will be expanding it into a full compiler for a C based language. It takes a text file as input and breaks it down into the following tokens:
  • Identifiers
  • Keywords
  • Integer Literals
  • Float Literals
  • String Literals
  • Operators
  • Delimiters
It also handles the end of the file and errors via their own tokens. Output displays the line/column of the first character in the token, the token type, the characters that make up the token, and finally the value of the token when applicable.

The following errors are supported:
  • Illegal Symbols: Unrecognized symbols and escape characters throw an error at the location of the character, with the message "Cannot resolve symbol ___". This is also thrown by characters that are legal on their own but not together, such as invalid escape characters and invalid operators.
  • Unterminated String: A string that isn't properly wrapped in quotation marks will throw an error. Multiline strings are accepted.
  • Unterminated Comment: Single line and multiline comments are accepted using C++ style syntax. An unterminated multiline comment throws an error.
  • Malformed Floating Point Literal: Floating point numbers such as 1..5, .5.2, .4., and . throw an error.
A full list of legal keywords, operators, escape characters, etc. can be found on GitHub.

Wandering in the Woods

Python Numpy MatPlotLib

This program runs simulations of two strangers wandering randomly in the woods until they meet. It takes a grid size from the user, a time limit per simulation, and a number of simulations to run. It then gathers key statistics on their movements as they go, ending either when the time limit finishes or when they meet. The program then outputs to the user key insights on the different simulations, with standouts being a histogram of ticks per simulation and a heatmap of meeting locations. All statistics are then saved to a timestamped output file.

Sorting Algorithm Library

C++

This is a library of the major sorting algorithms, all hand coded as an exercise in my C++ course.
Also included is a program for evaluating the efficiency of each algorithm comparatively.

The testing program takes a text file as input and reads it into memory as a vector. It then applies the five implemented sorts on the vector, being selection sort, insertion sort, bubble sort, merge sort, and quick sort. The results of the algorithm are written to a new file, and this file is then verified to be sorted in ascending order. Finally, a table is output showing the time in milliseconds that each sort took.

Tabletop Tinkerer

HTML/CSS/JS Node.js Express.js React

This is a full-stack demo app featuring user authentication, account management, and a persistent database backend, all built as the foundation for a Warhammer 40k Calculator.

The backend is build with Node/Express to implement a full account system. User account information is stored persistently in a PostgreSQL database, which is fetched from to autofill information or to verify user credentials using JWT-based authorization (the passwords to which are fully hashed using bcrypt).
The calculator logic is not built, primarily as this is a demo meant to focus on the account infrastructure that the real site would need.
